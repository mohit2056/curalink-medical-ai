## 💡 The Problem We Solved
Navigating medical research papers and clinical trials can be incredibly complex and stressful for the average person. The internet is filled with misinformation that often exacerbates patient anxiety. 

**Curalink AI** is the solution. It acts as an empathetic and highly accurate AI assistant that fetches real-time data from trusted medical databases (like PubMed and ClinicalTrials.gov) to provide calming, structured, and evidence-based summaries.

---

## ✨ Key Features
- **🧠 AI-Driven Reasoning:** Utilizes powerful Hugging Face Large Language Models to simplify and interpret complex medical data.
- **📚 Real Citations:** Provides direct links to actual research papers and clinical trials for every medical query to ensure authenticity.
- **🌸 Glassmorphism UI:** Features a modern, visually soothing frosted-glass interface intentionally designed to reduce patient anxiety.
- **🕒 Smart Query History:** Automatically saves the user's last 5 queries locally for quick and easy access without requiring complex logins.
- **📱 PWA Integration:** Fully installable as a Progressive Web App (PWA) on mobile and desktop devices for a seamless, app-like experience.
- **🚀 Scalable MERN Architecture:** Built on a scalable backend and a highly optimized frontend, ensuring zero-lag interactions.

---

## 🛠️ Tech Stack

**Frontend:**
- **React.js** (Powered by Vite for lightning-fast builds)
- **Custom CSS3** (Advanced Glassmorphism & UI Layers)
- **React-Markdown** (For rendering professional, formatted medical reports)
- **Lottie Player** (For engaging, lightweight medical animations)
- **Vite PWA Plugin** (For offline capabilities and installability)

**Backend:**
- **Node.js & Express.js** (Robust server architecture)
- **Hugging Face API** (AI/LLM processing engine)
- **MongoDB** (Caching, MERN stack compliance, and data management)
- **CORS** (Secure cross-origin communication)
